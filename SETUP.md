# Setup

1. Download and extract this bundle.
2. Create or open the public repository named `kanagaabishek` (same as your GitHub username).
3. Copy `README.md` and the `assets/` directory into the repository root.
4. Commit and push. Relative paths such as `./assets/hero.svg` will then render.
5. Replace generic project links with direct repository links once you decide which repos to feature.

## README interactions

GitHub sanitizes arbitrary HTML and does not execute JavaScript/React inside a README. This profile uses:
- custom animated SVG artwork;
- native Markdown anchor navigation;
- expandable `<details>` case-study sections;
- linked profile, project, and contact actions;
- live GitHub activity widgets.

For true click-driven filters, hover effects, a 3D scene, or a contact form, publish a separate portfolio site (e.g. Next.js) and link it from the profile README.
