<h3>LUMEN</h3>
<sub><b>DISTRIBUTED TRACING</b></sub>
<p><b>Problem</b><br/>Slow distributed requests leave engineers hunting through spans to find the critical path.</p>
<p><b>Solution</b><br/>Self-hosted OpenTelemetry tracing with gRPC ingestion, Cassandra storage, trace reconstruction, and latency analysis.</p>
<p><b>Impact</b></p>
<ul>
<li>Critical path, bottleneck, idle-gap, and self-time analysis</li>
<li>Batch writers flush 500 spans / 100 ms</li>
</ul>
<p><b>Engineering decision</b><br/>Merge overlapping child-span intervals before computing self-time. Decouple ingestion and persistence with a bounded queue.</p>
